# 管理画面の日別利用実績

Mojidas管理の「Mojidas利用実績」（`/admin/mojidas-usage`）で対象月を選択する。
日本時間で月初から月末まで、実績のない日も含めて表示する。初期値は当月。

- 無料分：月次無料枠と無償提供（新規登録プレゼント等）の消費。
- 有料分：購入時間の消費。購入金額・付与時間ではない。
- 法人プラン：法人利用台帳の消費。トライアル等も含むため有料分とは別列。
- 区分不明：過去の履歴から区分を復元できない消費。合計には含む。
- テスト枠は既存月別集計と同じく対象外。削除済み履歴は復元できない。

リアルタイムは消費報告日、ファイル認識と正式翻訳は精算日に計上する。
実際の録音時刻への日跨ぎ按分ではない。予約・返却・再予約は加算せず、
取消・期限切れでも確定消費があれば集計する。法人分は利用台帳の記録日で計上する。
時間は小数第3位まで表示するが、合計は丸める前のミリ秒から計算する。

既存の管理者認証を使用し、Firestoreの読み取り専用トランザクションで履歴を取得する。
既存月別集計との整合性のため個人分の履歴を全件読み、法人台帳も同時点で読む。
履歴増加時には集計済み日別データの導入を検討する。日時不明件数は全期間の値。

検証：`node tests/mojidas_daily_usage_report.test.js`。
公開後は管理者で9月を選び30行と月合計を確認し、別月への切替を確認する。
